# UU Box（原 DjuuMusic）

[m.djuu.com](https://m.djuu.com/)（DJ呦呦）的第三方 iOS 原生客户端：DJ 舞曲/串烧在线播放，SwiftUI + Liquid Glass UI，支持播放队列、收藏音乐盒、锁屏/控制中心/灵动岛媒体控制与 CarPlay。

> 本项目不发布 App Store，仅以未签名 IPA 形式分发，供个人通过 轻松签/全能签 等工具自签安装。

## 构建

- Xcode 26+，iOS 26.0+，`xcodegen` 生成工程后 `xcodebuild` 构建。
- 真机安装：以 Release 配置打出未签名 IPA，自签后安装。
